About This Project

What Is PyBot?

PyBot is a SaaS-style Python learning chatbot built as a GenAI assignment for the SureTrust program. It demonstrates a specific AI architecture concept: a chatbot without history.

Most AI chatbots work by accumulating a conversation — every message you send includes all previous messages as context for the next response. PyBot deliberately removes this: each question is answered completely fresh, with no knowledge of what was asked or answered before.

This is not a missing feature — it is the core design. For learning individual Python concepts, independent answers are often clearer and less prone to context drift than multi-turn conversations.

How It Works

  1. 1 You type a Python question into the chat input.
  2. 2 PyBot sends only that question plus a fixed system prompt to the AI.
  3. 3 The AI answers your question without any knowledge of previous questions.
  4. 4 The answer appears in the chat area for your reference.
  5. 5 Your next question starts the same process from scratch.

🔍 No-History Guarantee

  • ✅ Each request contains only the current question
  • ✅ No previous messages ever included in AI requests
  • ✅ No localStorage or sessionStorage conversation data
  • ✅ No database or server-side chat storage
  • ✅ Clear Chat removes all visible messages
  • ✅ Refreshing the page clears all messages permanently
